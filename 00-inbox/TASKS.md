# Tasks Dashboard

> [!info] Aggregator File
> This file aggregates tasks from across the vault using Obsidian Tasks plugin queries.
> **Do not add tasks here manually.** Add tasks to braindumps, project files, or daily notes instead.

## Overdue
```tasks
not done
due before today
sort by due
sort by priority
```

## Due Today
```tasks
not done
due today
sort by priority
```

## Due This Week
```tasks
not done
due after today
due before in 7 days
sort by due
sort by priority
```

## Upcoming (No Date)
```tasks
not done
no due date
sort by priority
group by path
```

## By Project
```tasks
not done
has due date
sort by due
group by folder
```

## Completed (Last 7 Days)
```tasks
done
done after 7 days ago
sort by done reverse
```
